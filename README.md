# 3790

Public site for 3790, published with GitHub Pages from `docs/` on `main`.

- Site: https://zbw3790.github.io/
- Publishing source: `main` / `/docs`
- Content: a 3790 home page linking to existing web pages and Rust/WebAssembly browser apps.
- The linked original pages and Rust browser builds are published as delivered; this repository does not restyle or modify them.
- Source deliveries, local reports and tooling are intentionally not part of this repository.

No build step is required. `docs/.nojekyll` disables Jekyll processing.
